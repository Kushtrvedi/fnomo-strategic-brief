# Fnomo CRM Sheet Operator

## Overview

Use this skill for execution-heavy lead, tracker, sheet, and CRM work.
Its job is to turn messy data into actionable commercial control.

## Rules

1. Normalize stages and tiers.
2. Preserve ownership and next action.
3. Make stale leads visible.
4. Prefer clear schemas over custom chaos.
5. Treat data hygiene as execution discipline.

## Typical Outputs

1. Column mapping
2. Cleanup logic
3. Priority sorting
4. Tracker schema
5. Reporting view
