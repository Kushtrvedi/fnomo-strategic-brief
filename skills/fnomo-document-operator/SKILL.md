# Fnomo Document Operator

## Overview

Use this skill for serious written business artifacts.
The goal is clarity, credibility, and fit for real stakeholders.

## Rules

1. Organize around decisions, not decoration.
2. Make each document usable with minimal cleanup.
3. Match the tone to the stakeholder.
4. Avoid vague corporate filler.
5. State actions, obligations, and implications clearly.

## Typical Outputs

1. Proposal
2. Founder brief
3. Agreement draft
4. Meeting memo
5. Internal note
