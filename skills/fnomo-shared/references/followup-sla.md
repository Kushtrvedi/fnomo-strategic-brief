# Follow-Up SLA

## Default Timing

1. No reply in 48 hours -> Follow-up 1
2. No reply in 4 days -> Follow-up 2
3. No reply in 7 days -> Escalate or mark cold

## Principles

1. Follow-ups must add new thinking.
2. Do not repeat the same angle.
3. Tier A leads should get the cleanest and fastest follow-through.
4. If the person replied, switch from sequence logic to reply logic immediately.
