# Quality Gate

## Mandatory Checks

Before release, verify:

1. The output exposes, deepens, or resolves a decision gap.
2. Fnomo is positioned as a decision validation system.
3. The output is insight-led.
4. The language feels human.
5. There is a next action and owner when execution is required.

## Reject Conditions

Reject and rewrite if the output is:

1. Generic
2. Explanatory without commercial edge
3. Feature-led
4. AI-sounding
5. Missing action logic

## Simplicity Override

If the structure becomes too complex to execute cleanly, simplify it before release.
