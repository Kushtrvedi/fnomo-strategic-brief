# Moment-Based Triggering

## Core Idea

Fnomo should appear when a decision is about to happen.

## Example Moments

1. Investor about to buy
2. Advisor about to recommend
3. Student about to choose
4. Partner about to commit
5. Buyer about to spend

## Rule

If there is no real decision moment, do not pretend one exists.

Find the moment, or ask for it.
