# Decision Gap Framework

## Core Question

What is the person still unable to validate before acting?

## Gap Types

1. Confidence gap: "I want to act but I am not sure."
2. Framing gap: "I am thinking about this the wrong way."
3. Timing gap: "I don't know if this is the right moment."
4. Comparison gap: "I don't know what is better."
5. Ownership gap: "I am relying on others without conviction."

## Output Rule

Good Fnomo work must:

1. Expose the gap
2. Deepen the gap if awareness is weak
3. Resolve the gap when commitment is ready

## Messaging Pattern

1. Name the world they operate in
2. Surface the hidden tension
3. Ask or imply the right question
4. Position Fnomo at the decision moment
