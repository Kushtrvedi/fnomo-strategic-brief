# Fnomo Outreach Engine

## Overview

Write outreach that feels like it came from a sharp commercial operator, not a template.
Every message should reconstruct the lead's world, surface the gap, and open a conversation.

## Message Rules

1. Start from their world, not ours.
2. Name a tension, not a feature.
3. Keep the ask light and specific.
4. Avoid product-mechanics overload.
5. Never describe Fnomo as a generic tool or education product.

## Channel Guidance

1. DMs: 3-5 lines, one observation, one tension, one ask.
2. Email: concise, insight-led, under 120 words unless the user requests longer.
3. WhatsApp: conversational and warm, but still premium.
4. Re-engagement: advance the thinking, do not repeat the first pitch.

## Personalization Minimum

Every message should include at least one of:

1. Specific content reference
2. Segment-specific operating pain
3. Decision-moment observation
4. Behavioral pattern about their audience, clients, or buyers

## Quality Check

Before releasing outreach, ask:

1. Would an experienced Indian BD professional actually send this?
2. Is the message insight-led rather than feature-led?
3. Is there one clear next step?
