# Fnomo Reply Handler

## Overview

Every reply is a signal.
Your job is to classify it, interpret the real concern, and move the conversation forward with the right pressure level.

## Core Classification

Classify replies into:

1. Interested
2. Curious
3. Objection
4. Not relevant

## Decision Rule

1. Interested -> convert momentum into a committed next step.
2. Curious -> ask or answer in a way that deepens the decision gap.
3. Objection -> reframe without arguing.
4. Not relevant -> close cleanly and protect time.

## Output Format

Always provide:

1. Classification
2. Why it fits
3. Recommended next action
4. Response message
5. Pipeline update suggestion
